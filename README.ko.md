# Switch 병합 / 분리 툴 (GUI)
Nintendo Switch NSP, NSZ, XCI, XCZ 파일을 병합 및 분리 GUI 툴
디스크에 임시 파일을 생성하지 않는 스트리밍 파이프라인 방식

---

## 주요 기능

### 본편, 업데이트, DLC를 하나의 파일로 병합

- 드래그 앤 드롭 지원
- 자동 포맷 감지
- 병합 시 압축 옵션 지정 가능 ( NSZ )

### 병합된 파일을 개별 파일로 분리

- 본편, 업데이트, DLC를 별도 파일로 분리

---

## 지원 포맷

- NSP (병합 / 분리)
- XCI (병합 / 분리)
- NSZ (병합 / 분리, 자동 압축 해제)
- XCZ (병합 / 분리, 자동 압축 해제)

모든 결과는 NSP, NSZ 파일로 출력됩니다.

---

## 자동 압축 해제

압축 포맷 사용 시:

- NSZ 파일 자동 압축 해제
- XCZ 파일 자동 압축 해제

압축 해제는 동시에 진행됩니다.

---

## 스트리밍 처리 방식

이 도구는 스트리밍 파이프라인을 사용하여:

- 병합 및 분할 과정 중 데이터를 실시간 처리
- 임시 파일 생성 방지
- 디스크 사용량 감소
- 성능 향상

### 기존 방식

1. NSZ/XCZ 압축 해제
2. 임시 NSP 생성
3. 병합 또는 분할 수행

이 툴은 모든 작업을 동시에 진행합니다.
